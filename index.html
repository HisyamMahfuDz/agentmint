AgentMint

A free NFT mint for Agent ID holders on BNB Chain. One mint per Agent ID holder, no payment, no fees, no allowlist. The contract never holds funds — minting is free, you only pay network gas.

How it works: the contract checks the official Agent ID registry (0x60B9262456dE011F7d15a54CdD8c48bAaa8B022F) — if your wallet holds an Agent ID, you can mint exactly one AgentMint NFT for free. Metadata is generated fully on-chain, so the collection needs no hosting.

Open source: contract AgentMint.sol (MIT), verified on BscScan after deployment. Built for the Binance Agent ID Hackathon.
